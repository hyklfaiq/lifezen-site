FAQ

Quick answers.

Is there an iOS version?

Not currently. LifeZen is released as an Android APK (API 21+).

Do I need an account?

No. Core features work without one and store data locally.

Is the i-Ma'luum import official?

No. It is a convenience feature from an independent student project, not an IIUM service.

Which technologies does it use?

Flutter and Dart, with Shared Preferences, Local Notifications and Image Picker.
